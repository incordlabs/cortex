# Cortex CPU Backend

[Cortex](https://github.com/qora-protocol/cortex) CubeCL CPU backend

[![Current Crates.io Version](https://img.shields.io/crates/v/cortex-cuda.svg)](https://crates.io/crates/cortex-cuda)

This crate provides a MLIR based CPU backend for [Cortex](https://github.com/qora-protocol/cortex) using the
[cubecl](https://github.com/qora-protocol/cubecl.git) crates.
